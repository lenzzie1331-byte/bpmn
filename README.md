# Моделирование бизнес-процессов: Запись и приём пациентов в клинике (AS-IS / TO-BE)

## Цель и бизнес-контекст
Проанализировать текущий процесс записи пациентов на приём в медицинскую клинику, выявить узкие места (ручная обработка звонков администратором, необходимость обзвона за сутки до приёма) и спроектировать целевой процесс онлайн-записи через сайт клиники.

## Проработанные диаграммы (вкладки файла `bpmn.drawio`)
В проекте представлены три модели в нотациях BPMN 2.0 и UML:

* **`as-is bpmn` (Текущий процесс):** моделирование взаимодействия ролей *Администратор*, *Пациент* и *Врач*. Описаны шаги телефонной записи, ручной сверки расписания в календаре, контрольного обзвона за сутки до визита, проведения осмотра и назначения лечения.
* **`as-is uml smd` (Диаграмма состояний записи):** жизненный цикл сущности «Запись на приём» и переходы между статусами (*Создан* -> *Ожидает подтверждения* -> *Подтверждён* / *Отменён* -> *В работе* -> *Завершён*).
* **`to-be bpmn` (Целевой процесс):** оптимизированный процесс с автоматизацией записи через сайт клиники. Исключена ручная рутина администратора — пациент самостоятельно выбирает врача, дату и время приёма, после чего сразу попадает в расписание врача.

## Инструменты и нотации
* **Нотации моделирования:** BPMN 2.0 (пулы, дорожки, шлюзы, события по таймеру), UML State Machine Diagram
* **Инструмент:** Draw.io

## Структура репозитория
* `bpmn.drawio` — исходный файл со всеми тремя диаграммами (для просмотра откройте в [diagrams.net](https://diagrams.net) или десктопном приложении Draw.io).
* `README.md` — описание цели проекта, анализируемых процессов и результатов оптимизации.
