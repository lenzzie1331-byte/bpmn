# Моделирование бизнес-процессов: Запись и приём пациентов в клинике (AS-IS / TO-BE)

## Описание и цель проекта
Проанализировать текущий процесс записи пациентов на приём в медицинскую клинику, выявить узкие места и спроектировать целевой процесс онлайн-записи. 
**Стек и инструменты:** BPMN 2.0, UML State Machine Diagram, Draw.io, Markdown.

## Проработанные диаграммы (вкладки файла `bpmn.drawio`)
* **`as-is bpmn` (Текущий процесс):** взаимодействие ролей *Администратор*, *Пациент* и *Врач* при записи по телефону, ручной сверке расписания, контрольном обзвоне за сутки до визита и приёме.
* **`as-is uml smd` (Диаграмма состояний записи):** жизненный цикл записи на приём и переходы между статусами (*Создан* -> *Ожидает подтверждения* -> *Подтверждён* / *Отменён* -> *В работе* -> *Завершён*).
* **`to-be bpmn` (Целевой процесс):** оптимизированный процесс с автоматизацией записи через сайт клиники.

## Выводы и результаты проекта
* **Выявлены узкие места (AS-IS):** высокая нагрузка на администратора из-за ручной обработки входящих звонков, сверки календаря и обязательного обзвона пациентов за сутки до приёма, а также риск потери заявок при недозвоне.
* **Предложено решение (TO-BE):** внедрение формы самозаписи на сайте клиники полностью снимает рутинную нагрузку с администратора, сокращает время записи пациента до нескольких кликов и исключает этап ручного подтверждения по телефону.

## Как открыть схемы
Скачайте файл `bpmn.drawio` и откройте его через бесплатный веб-редактор [app.diagrams.net](https://diagrams.net) (*File -> Open from -> Device*) или в десктопном приложении Draw.io.

## Структура репозитория
